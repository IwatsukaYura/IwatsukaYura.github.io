## DVA ってどんな試験？

AWS 上でアプリケーションを開発・デプロイ・デバッグするための知識を問われる、アソシエイトレベルの試験です。現行の試験コードは DVA-C02 です。

- 問題数: 65 問（うち 15 問は採点されない調査用の問題）
- 試験時間: 130 分
- 形式: 択一式 / 複数選択式
- 合格ライン: 720 / 1000

出題分野と配分は次のとおりです。

| 分野 | 配分 |
| --- | --- |
| AWS のサービスを使用した開発 | 32% |
| セキュリティ | 26% |
| デプロイ | 24% |
| トラブルシューティングと最適化 | 18% |

同じアソシエイトの SAA（ソリューションアーキテクト）が「どう組み合わせて設計するか」寄りなのに対して、DVA は「SDK や API をどう使うか」「設定値や制限がどうなっているか」といった、開発者目線の細かい仕様を問われる印象でした。【TODO: 実際に受けてみての印象に合わせて調整】
